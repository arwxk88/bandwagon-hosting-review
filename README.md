## 官网不会放在显眼位置的几个限制

这些信息散落在条款和页面角落，但每一条都可能影响你的决定：

- **严格自助管理**：官方原话是 self-managed 让他们能把价格压下来。环境配置、故障排查全靠自己，没有托管服务，出了问题只能查文档和搜社区。
- **只有 Linux**：官方系统列表是 AlmaLinux、RockyLinux、CentOS、Debian、Ubuntu、Fedora 等，支持手动挂载 ISO，没有 Windows。管理方式是 SSH（PuTTY、XShell 这类工具），完全不会命令行的话上手会很痛苦。
- **无 DDoS 防御**：前面说过，再强调一次是因为这点被问得多。
- **换 IP 要花钱，且换过影响退款**：付费更换 IP 目前约 $8.79 一次；更重要的是，只要申请过换 IP（无论免费还是付费），退款资格就没了，想保留退款后路就先别动 IP。
- **续费有时间窗口**：不支持提前续费。到期前 7 天系统自动生成账单并发邮件（发件人 Bandwagon Host，收不到先翻垃圾箱），账单生成后约 7 天内付款，期间 VPS 正常跑；逾期未付会停服，且停了就没法再补续。系统逾期前会发 1–3 封提醒邮件，别当垃圾邮件删了。
- **微信支付已取消**：曾经支持，接口已下线。购买和续费账单可用支付宝、银联、PayPal、信用卡；给账户余额充值只支持 PayPal 和信用卡。官方不会自动从支付宝扣款，也不存储你的支付信息，没有“自动续费扣款”的坑——想自动续费只能提前充值余额。
- **官网偶尔抽风**：有用户反映主站个别时段访问不稳定，遇到打不开的情况换个时间或网络再试即可。注册只需邮箱，全程英文界面。

## 退款政策：有 30 天保证，但条件比你想的多

搬瓦工对新账户提供 30 天内全额退款，款项原路退回（支付宝付的退支付宝），审核是全自动的。听起来很宽松，实际有 8 个条件要同时满足，其中几条最容易被忽视：

1. **30 天从账户创建算起，不是从购买算起**。注册了账户放着，一个月后才买第一台 VPS，照样不能退。
2. **月流量用量要低于套餐总流量的 10%**。1TB 套餐的阈值大约是 100GB，买来测速、跑几天服务，很容易就超了。
3. **账户总支付金额不超过 $100、次数不超过 10 次**。先买便宜款再补单高配，两单加起来超了 $100，退款资格就没了。
4. **IP 动过就不行**。IP 进黑名单或申请过换 IP，都会被拒。
5. **续费订单不退**，而且每人只有一次退款机会，用过永久失效。

执行层面还有三个细节：退款是**全账户退款**，账户下所有 VPS 一起终止，不支持只退一台；退款提交后所有数据、快照、备份立即删除且不可恢复，所以提交前先把数据备份到本地；流程走到最后一步，系统会发一封确认邮件，**必须只回复 "I agree" 这两个词**——加了别的内容自动化系统识别不了，退款会自动取消。到账速度方面，支付宝和 PayPal 一般半小时内，信用卡要 3–14 个工作日。

另外千万别为了退款去发 PayPal dispute（争议），官方条款写明这会导致名下及关联账户全部服务暂停，还要按每小时 $40、15 分钟一个时段收取处理费。

一句话：退款窗口是真的，但要当成“确认是否适合”的试用通道来用——买之前再注册账户，30 天内小流量测试，确认合适就留下，不合适早点退。
